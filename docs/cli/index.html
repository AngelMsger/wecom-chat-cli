wecom-chat-cli

Isolate agents from untrusted WeCom smart-bot conversations

Usage:
  wecom-chat-cli [flags]
  wecom-chat-cli [command]

Available Commands:
  auth        Read credential provisioning guidance
  broker      Run the credential-holding operator service
  config      Inspect operator policy
  event       Operator-only event discovery and monitoring
  memory      Manage scoped sender risk records
  reply       Propose immutable replies and independently review sends
  session     Operator-controlled conversation fences
  status      Inspect broker connectivity and scope
  task        Issue or consume single-event worker grants
  version     Show the local CLI version

Flags:
      --allow-writes        Permit this invocation's mutation; grants no server authority
      --bot-id string       Expected bot ID from the operator
      --deployment string   Expected deployment name from the operator
      --dry-run             Validate a write without state changes or remote sends
      --format string       Output: json or ndjson (trust fields cannot be removed) (default "json")
      --socket string       Absolute worker or trusted operator Unix socket path

Use "wecom-chat-cli [command] --help" for more information about a command.
